# 插件化课程：安装示例

这个目录展示任务插件的安装、课程配置与读取方式。课程材料由相邻的分治法案例提供。

## 使用顺序

1. 阅读[课程学习规范](../../standards/上下文规范/课程学习/课程学习上下文规范.md)，在自己的课程建立 `.agent/memory.md`、`progress.md`、`completed_tasks_log.md`。
2. 从[中央插件索引](../../standards/上下文规范/.agent/memory.md)选择任务。这里展示已安装的“ASR录播整理”和“课程讲解与答疑”。
3. 将正文复制到该课程 `.agent/plugins/`，在 `memory.md` 登记名称、版本、本地位置、触发时机和课程配置。
4. 有课程要求时，在本地插件开头增加“课程特化规则”；通用正文独立保留，升级时比较后更新。
5. 按当前任务的读取时机，加载课程入口登记的本地插件。

入口：[本示例 `.agent/memory.md`](.agent/memory.md)。课程材料见[分治法案例](../algorithm-divide-conquer/README.md)。

## 一个使用场景

用户提出“先了解 4 月 2 日讲了哪些重点，再开始学习 Karatsuba”：

- 先按 ASR 插件读取概述，必要时回到完整转录，并查课件对应页。
- 进入学习时按课程讲解插件确认要采用的资料和讲解节奏。
- 整理新笔记时读取完整课件笔记规范，保留页码、推导、配图与课堂补充。
- 学习推进写 `progress.md`，阶段完成写历史；资料入口变化再更新 `memory.md`。

实验报告、习题讲评等任务也可以编写为插件，说明任务前提、读取时机、文件范围、流程和产物，再安装并登记到课程入口。
