## 维护与插件约定

先读入口和进度，再按当前任务加载有关资料。推进写进度，完成写历史，稳定资料变化更新入口。已安装不等于自动加载：只在符合读取时机时读取本地插件。

增加插件时查看[中央索引](../../../standards/上下文规范/.agent/memory.md)，确认后复制正文并登记。课程专用约定放在本地插件开头；更新时比较通用规则并保留特化，规范库不会自动覆盖课程副本。
