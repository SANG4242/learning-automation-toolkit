# Hub 工具使用指引：音视频

读取时机：YouTube/B站下载、音频转录、语音转文字、JSON 字幕转换或根据视频整理图文笔记时。相对资源路径以 `D:\Antigravity-Hub` 为基准；`Hub\` 指 `D:\Antigravity-Hub\`。

## 转录进度输出

- 语音转录与精细对齐默认在当前终端直接实时输出启动状态、分块完成数、耗时及结果路径，Python 使用 `-u` 无缓冲模式。
- 此类长任务的进度日志优先实时显示，作为通用长输出重定向规则的专项例外；需要保存日志时同步显示到终端，并保留原进程退出码。

## 工具入口

| 任务类型 | 执行前必读 |
| --- | --- |
| YouTube/B站 字幕/音频/视频下载 | `yt-dlp` 已全局安装（v2026.3.17）。**YouTube/B站均推荐 Firefox 自动读取 cookies**（用 `--cookies-from-browser firefox`，免手动维护）。**YouTube** 需另加 deno（命令前加 `$env:PATH = "$env:USERPROFILE\.deno\bin;$env:PATH";`）和 `--remote-components ejs:github`。**B站** 直接使用 cookies 即可，无需其他参数。详见 `工具脚本\yt-dlp\README.md` |
| 本地语音转文字（ASR） | 音视频放 `Hub\temp\语音转录\audio\`；每次任务输出到 `output\任务名\`。**首选 Qwen3-ASR + vLLM**：`python -u "D:\Antigravity-Hub\工具脚本\语音转录\transcribe_qwen_vllm.py" -f "文件名(多个文件用英文逗号分隔)" [-l en] [-d "任务父目录"]`。脚本自动拉起 WSL vLLM，默认 5 路并发，以 150 秒为硬上限在 120～150 秒寻找低能量切点，使用 ONNX CPU VAD 跳过无声块；任务目录内生成 `transcript.md`、`chunks.json` 与 `chunks\`。**精细时间戳**：`& "D:\Apps\Miniconda3\envs\qwen3-asr\python.exe" -u "D:\Antigravity-Hub\工具脚本\语音转录\align_qwen.py" "任务目录\chunks.json" --stop-vllm`，生成 `alignment.jsonl` 与 `sentences.jsonl`。**查询**：`python "D:\Antigravity-Hub\工具脚本\语音转录\query_timestamp.py" "任务目录\sentences.jsonl" "句子ID或原文"`。备选脚本也按任务目录输出。详见 `工具脚本\语音转录\README.md` |
| B站 JSON 字幕转换 | 脚本 `工具脚本\语音转录\bilibili_json_to_txt.py`。**简介**：将 B 站下载的 JSON 格式字幕转换成带时间戳 `[MM:SS]` 的文本（默认输出为 `.md` 格式）。**参数命令**：`python "D:\Antigravity-Hub\工具脚本\语音转录\bilibili_json_to_txt.py" <JSON文件或目录或多个路径> [-o 输出路径] [--txt]`（使用 `--txt` 参数可强制输出为 `.txt`）。**运行示例**：① 目录批量转换（默认 `.md`）：`python "D:\Antigravity-Hub\工具脚本\语音转录\bilibili_json_to_txt.py" "D:\Antigravity-Hub\temp\语音转录\output"`；② 单个文件转换并强制输出 `.txt`：`python "D:\Antigravity-Hub\工具脚本\语音转录\bilibili_json_to_txt.py" "D:\Edge Downloads\sub.json" -o "d:\sub.txt" --txt`。 |
| 视频图文笔记 | 用户要求“把这个视频整理成图文笔记”、根据视频做笔记并保留关键截图时，先读取 `规范\笔记整理规范\.agent\memory.md`，再按其索引读取 `视频图文笔记处理流程.md` 及已登记的视频整理规范；默认运行本地 Qwen3-ASR 与精细对齐，平台字幕同步获取并用于对照、补漏和纠正专有名词，再按本地转录原文定位时间、使用 FFmpeg 抽取候选帧、完成视觉筛选及 Typora `.assets/` 插图。 |
