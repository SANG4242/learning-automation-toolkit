# Hub 工具使用指引：课程

读取时机：Canvas 课程、作业、截止时间、提交状态与反馈查询，同济 look 课程录播下载、YourTJ 选课点评、课表查询与导出时。相对资源路径以 `D:\Antigravity-Hub` 为基准。

本地脚本统一入口（YourTJ、课表、look）：`工具脚本\课程工具统一入口\course_tools.py`。先运行 `python "D:\Antigravity-Hub\工具脚本\课程工具统一入口\course_tools.py" doctor` 检查 Python、目标脚本、Firefox 配置和 `curl.exe`；完整说明见同目录 `README.md`。

| 任务类型 | 可直接执行的入口 |
| --- | --- |
| Canvas 课程与作业平台 | 用户平时查看课程、课件、公告及提交作业的平台：`https://canvas.tongji.edu.cn`。优先使用已注册的 `canvas-course-assistant` MCP，调用前读取对应工具描述，认证由现有 MCP 配置提供。`canvas_query` 查询课程及资源摘要，`canvas_assignments` 查询作业、截止时间与提交状态，`canvas_detail` 读取作业正文、提交反馈等详情。示例：`canvas_query({"resource":"courses","search":"系统分析","course_scope":"active"})` → 使用返回的课程 ID 调用 `canvas_assignments({"course_id":115967,"mode":"all"})` → 使用返回的作业 ID 调用 `canvas_detail({"resource":"assignment","course_id":115967,"resource_id":118277})`；示例 ID 仅属于该课程，不用于其他课程。课程范围、分页与正文续读按工具描述处理，截止时间采用返回的当地时间。工具直接返回查询结果；查询提交状态与反馈属于只读操作，上传及最终提交须另行取得用户授权，当前注册的查询工具不提供提交能力。 |
| YourTJ 课程、评价与排课查询 | 无需登录。课程搜索：`python "D:\Antigravity-Hub\工具脚本\课程工具统一入口\course_tools.py" yourtj search 软件工程`；排课搜索：`python "D:\Antigravity-Hub\工具脚本\课程工具统一入口\course_tools.py" yourtj schedule-search 122 --teacher 朱宏明`；支持点评导出与 `--json`。排课高级搜索最多返回 100 门。帮助：`python "D:\Antigravity-Hub\工具脚本\课程工具统一入口\course_tools.py" yourtj --help`；权威说明见 `工具脚本\选课点评助手\README.md`。 |
| 同济全校课表导出与查询 | 联网抓取前需在 Firefox 登录一系统；已有缓存可离线使用。导出：`python "D:\Antigravity-Hub\工具脚本\课程工具统一入口\course_tools.py" schedule export -c 122 -f json`；查询：`python "D:\Antigravity-Hub\工具脚本\课程工具统一入口\course_tools.py" schedule query 大三上 数据库`；学期映射：`python "D:\Antigravity-Hub\工具脚本\课程工具统一入口\course_tools.py" schedule query --show-semesters`。查询脚本缺少 CSV 时会自动调用导出脚本。默认结果位于 `工具脚本\同济课表导出\.cache\`，详细说明见该目录 `README.md`。 |
| look 课程录播与课件 | 需在 Firefox 登录 look，视频下载还需 `curl.exe`。搜索：`python "D:\Antigravity-Hub\工具脚本\课程工具统一入口\course_tools.py" look search 数据库`；录播：`python "D:\Antigravity-Hub\工具脚本\课程工具统一入口\course_tools.py" look download 86038 2026-05-11`；课件：`python "D:\Antigravity-Hub\工具脚本\课程工具统一入口\course_tools.py" look ppt 86038`。默认保存到 `temp\语音转录\audio\`。`search-update` 和 `scan-search` 会进行高并发请求，只在明确需要时运行；详细说明见 `工具脚本\look课程录播\README.md`。 |
