# Hub 临时文件规范

读取时机：确定临时文件、命令输出或工具产物的存放位置时。`Hub\` 指 `D:\Antigravity-Hub\`。

## temp 文件规范

| 类型 | 位置 | 命名规则 |
| --- | --- | --- |
| 笔记 temp | `D:\TJU-Notes\temp\YYYY-MM\` | `temp_MM-DD_周X_xxx.md` ⚠️**周几务必确认** |
| 命令输出 | 项目有则放项目 `temp\cmd_output\`，否则放 `Hub\temp\cmd_output\` | 描述性名称（如 `git_log.txt`） |
| 临时脚本 | `Hub\temp\临时脚本\` | AI 测试/调试用的临时 Python 脚本 |
| MinerU转换 | `Hub\temp\MinerU转换\` | 脚本自动生成（带缓存检查） |
| PDF转图片 | `Hub\temp\PDF转图片\` | 脚本自动生成（带缓存检查） |
| PDF翻译 | `Hub\temp\PDF翻译\` | 自动生成 `{原名}-dual.pdf` 与 `{原名}-mono.pdf` |
| Word转PDF | `Hub\temp\Word转PDF\` | docx2pdf.py / doc2img.py 自动生成（路径命名法+缓存检查） |
| PPT转PDF | `Hub\temp\PPT转PDF\` | ppt2img.py 自动生成（路径命名法+缓存检查） |
| 网页抓取与归档 | `Hub\temp\网页抓取与归档\` | `SingleFile\`、`Trafilatura\`、`Crawl4AI\` 和 `日志\`；指定输出路径时覆盖默认位置 |
| WeFlow媒体 | `Hub\temp\WeFlow媒体\` | 【已废弃，会封号，禁止使用】 |
| **杂项** | `Hub\temp\杂项\` | 无固定归属的临时文件统一放此处，可随时批量清理 |
| **全局演练场** | `Hub\temp\playground\` | 全局临时草稿/测试目录（如 MCP 测试、临时 Demo），用完可随时清理 |
| **语音转录** | `Hub\temp\语音转录\` | `audio\`：待转录音频；`output\任务名\`：该次 ASR 的 `transcript.md/txt`、`chunks.json`、`chunks\`、`alignment.jsonl`、`sentences.jsonl`；平台字幕等非 ASR 对照材料可保留在 `output\` |
| **视频图文笔记** | `Hub\temp\视频图文笔记\任务名\` | 保存下载视频、字幕、ASR 结果和候选帧；最终采用的图片复制到对应笔记的 `.assets/` |
