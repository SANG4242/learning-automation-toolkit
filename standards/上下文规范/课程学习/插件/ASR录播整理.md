# ASR 录播整理插件

> 插件版本：v2.0.0
> 最后更新：2026-10-13
> 用途：课程录播转录查阅、重点讲解、资料映射与概述整理。
> 安装位置：实际项目的 `.agent/plugins/ASR录播整理.md`。
> 读取时机：转录课程录播、整理或重整 ASR 概述、根据录播整理笔记、查阅录播授课内容时。

## 一、资料选择与任务流程

从项目 `memory.md` 的资料索引定位相关课次、原始转录、概述及课件或讲义，按任务选择输入：

| 任务 | 读取与处理 |
|---|---|
| 快速了解授课内容、查讲授范围 | 优先读取概述；无概述时按需读取原文 |
| 新建或重整概述 | 完整阅读对应转录，结合可用课件、讲义或板书核对 |
| 根据录播整理详细笔记 | 完整阅读对应转录，结合相关资料，并执行项目就近笔记规范 |
| 核对具体原话、术语或数字 | 读取对应原文时段及相关资料，必要时回听 |
| 转录录播 | 复用已有可用转录；缺少结果时使用已登记转录工具 |

- 同一章节可能跨多个课次，逐个转录阅读和处理；长文件可分段完整阅读。
- 只有转录时也可整理概述。课件、讲义及板书按实际可用资料核对，已有笔记不代替原始输入。
- 对术语、公式、数字和专有名词进行核对，标明仍未确认的信息；区分教师讲授、课堂例子与补充解释。
- 精细对齐用于有需要的句子级回听、字幕或截图定位。普通概述与笔记可使用已有分块时间戳。
- 生成转录或调用对齐工具前，读取 `D:\Antigravity-Hub\.agent\context\工具-音视频.md`；下载课程录播时同时读取 `D:\Antigravity-Hub\.agent\context\工具-课程.md`。具体命令、工具依赖和中间产物位置按工具指引执行。PDF 或其他文档读取按当前环境的文档规则执行。

## 二、概述定位与结构

概述用于快速了解本讲、理解重点并定位原录播，即使没有详细笔记也应能独立阅读。详细笔记承担系统讲解、完整推导和逐页学习。

按以下顺序组织概述；来源、录播时长等定位信息可放在开头或表格前。

### 1. 本讲概览

保留五项，覆盖全讲：

- **核心主题**：一句话说明本讲围绕的问题。
- **内容主线**：说明各部分的展开顺序和关系。
- **主要内容**：概括实际讲授的知识、方法、例题、推导和结论。
- **教师侧重点**：概括反复强调、额外补充或明确要求掌握的内容。
- **学习结果**：说明学完应理解或能够完成什么。

概览概括全局；具体知识解释放在重点部分，资料位置在对照表记录。

### 2. 重点内容与课堂补充

按知识主题简要讲解重要内容，让读者形成基本理解。根据材料选择需要说明的含义、关键关系、适用条件、主要步骤、公式、理由、课堂例子和易混点，附相关时间或资料位置便于回查。

主题数量、篇幅和表达方式依据内容复杂度及学习用途调整。有价值的课堂补充保留；重复强调归纳表达。考点标记依据教师说明或明确资料，普通重要知识标为重点。补充解释与原讲授内容注明来源区别。

### 3. 内容与时间对照表

采用两级内容组织：大模块下按连续讲授主题分行。五列分别为：

| 列 | 内容 |
|---|---|
| 内容模块（总时间跨度） | 模块名称和总时间范围；同模块首行填写，后续行留白，可用 `<br>` 分隔名称与时间 |
| 时间范围 | 连续内容段的实际起止时间，使用 `[mm:ss-mm:ss]`，超过一小时可用 `[h:mm:ss-h:mm:ss]` |
| 课件 / 资料对应 | 课件页码、讲义章节、题号等；注明课堂补充、无配套资料或位置待确认 |
| 本段主要内容 | 便于浏览和定位的主题名称 |
| 重点 / 课堂提示 | 关键结论、该时段特有案例及明确的考核、跳过或不讲提示 |

合并粒度按内容判断：

- 同一概念的连续解释、同一例子的步骤与结论、重复说明可合并为一行，连续休息或无人声合并记录。
- 新概念、独立例题、不同方法及独立课堂事项按需分行；一行含多个可独立定位的主题或过长时适当拆分。
- 同一主题在后面再次讲授，保留其独立时间位置；重点部分可统一归纳。
- 模块数、行数和时长随材料调整，转录分块只作为时间溯源依据。合并后的范围以原始时间戳为依据，内部边界不明确时注明近似位置。
- 表格简明记录讲授顺序和定位线索，具体解释集中在重点部分。

### 4. 课堂事项（按需）

集中记录实际出现的作业、考核要求、明确不讲或略过的内容、讲授边界及后续安排。课堂略过与明确不考分别记录。

## 三、存放与写回

- 常规课程按讲拆分，保存到 `.agent/asr概述/`，以日期加讲次或主题命名；短期少量资料可使用 `.agent/asr概述.md`，两种方式选其一。
- 正式可读转录保存到项目 `ASR转录/`；原始音视频与中间产物按工具指引存放。
- 生成或更新后，在项目 `memory.md` 登记资料、路径和用途；按项目维护规则写回已有进度或完成记录。资料整理完成与学习完成分别记录。

## 四、验收

- 概览覆盖全讲，重点内容能独立读懂，保留关键课堂补充及适用条件。
- 对照表主题清楚、顺序连贯，重要授课内容及休息可追溯到实际时间；合并重复表述后仍保留重要信息。
- 资料位置、术语和考核表述有依据；链接有效，正文、表格和课堂事项各有用途。
