| 通用项目 | 课程学习 |
| -------- | -------- |
| memory.md：项目概述 + 技术栈 | memory.md：课程信息 + 大纲 + 维护规则 + 插件索引 |
| progress.md：任务粒度 | progress.md：当前快照（里程碑 + 当前章节打卡 + 待办） |
| completed_tasks_log.md：任务归档 | completed_tasks_log.md：历史详档（逐节明细 + 答疑记录） |

## 📁 课程目录结构

```text
课程名称/
├── .agent/
│   ├── memory.md                 # 静态上下文（课程信息、大纲、维护规则、插件索引）
│   ├── progress.md               # 当前快照（里程碑 + 仅当前章节的详细打卡 + 待办）
│   ├── completed_tasks_log.md    # 历史详档（已完成章节的逐节明细 + 答疑记录表）
│   ├── plugins/                  # 已安装插件的本地副本（可选）
│   ├── context/                  # 课程长期上下文扩展（可选）
│   │   └── 笔记整理规范.md       # 课程专用笔记规范（需要个性化定制时创建）
│   └── asr概述/                  # ASR 录播整理插件的产物目录或 asr概述.md 文件（可选）
├── ASR转录/                      # 正式可读的完整转录 Markdown（可选）
├── 笔记/                         # AI 辅助生成的学习笔记
├── 课件/                         # 课程正式 PPT / PDF（可选）
└── 相关资料/                     # 截图、通知、教材和参考资料等（可选）
```

`plugins/` 只保存该课程已安装的插件。`context/` 保存课程长期生效的上下文扩展；课程需要个性化笔记规则时才创建 `context/笔记整理规范.md`。`ASR转录/` 只保存正式可读的完整转录 Markdown；原始音视频放在 Hub `temp\语音转录\audio\`，每次任务的转录、分块清单、分块 WAV 和对齐文件集中放在 `temp\语音转录\output\任务名\`。`课件/` 保存正式课件，截图、通知等辅助材料放入 `相关资料/`。各可选目录仅在实际有对应内容时创建。

```markdown
## 📋 三文件维护规则

> 本节是 memory.md 的核心，AI 每次对话读 memory.md 时自然会读到。

### 文件分工

| 文件 | 定位 | 只放 | 不放 |
|------|------|------|------|
| memory.md | 静态上下文 | 课程信息、大纲、目录结构、插件索引、本维护规则 | 任何会变动的进度 |
| progress.md | 当前快照 | 里程碑 + 当前章节（预估/明细/答疑）+ 待办 + 用时参考 | 已完成章节的内容 |
| completed_tasks_log.md | 历史详档 | 已完成章节的学习明细 + 答疑记录 + 笔记产出 | 当前进行中的内容 |

### 插件查找与维护

- “已安装插件”是本课程支持插件的唯一索引。当前学习任务符合某项读取时机时，读取表中登记的本地插件文件；未触发时不加载。
- 插件未在课程入口登记时，视为本课程未安装，不扫描目录或规范库猜测可用插件。
- 当前学习任务需要的能力不在课程入口，或用户要求新增能力、安装插件、升级插件、审查课程上下文时，读取 `D:\Antigravity-Hub\规范\上下文规范\.agent\memory.md` 的中央插件索引查找适用插件。
- 安装插件前取得用户确认；确认后将源文件复制到 `.agent/plugins/`，再在“已安装插件”中登记名称、本地文件、版本、读取时机和课程配置；课程配置优先于插件默认值。
- **插件特化机制**：
  - 当某门课程对已安装插件有专属的执行要求、术语约定或输出特化时，统一在本地 `.agent/plugins/插件名.md` 文件的开头设立固定章节 `## 课程特化规则`。
  - 无个性化要求的插件，该章节注明“暂无特化”或省略；复制来的中央插件原始正文保持独立与通用。
  - 特化要求优先于插件通用默认设定；若特化要求与通用设定冲突，执行时以特化要求为准。
- 升级插件时比较源版本与本地版本，只定向更新通用正文部分，**严格保留本地插件头部的课程特化规则**，禁止无差别直接覆盖；卸载时同步移除索引项，相关学习资料和产物是否删除另行确认。
- 日常学习只依赖课程 `.agent/` 中的入口和本地插件；规范库源文件仅用于安装、升级和审查。

### 课程专用笔记规范维护

- 课程专用笔记规范属于长期上下文扩展，保存于 `.agent/context/笔记整理规范.md`，并在“上下文索引”登记；它不属于插件，不登记到“已安装插件”。
- 用户要求对课程笔记进行个性化定制且本地规范尚不存在时，从全局笔记整理规范中选择与主要资料类型匹配的规范，完整复制到上述路径，并在文件开头新增固定章节“课程特化规则”。涉及多种资料类型时仍维护在同一文件中，并注明适用条件。
- 课程个性化要求统一写入“课程特化规则”，复制来的原始规范正文默认保持不变。
- 新增或调整课程特化规则时，先检查是否与原始规范正文冲突；存在冲突时列出冲突条款并询问用户是否修改或替换原条款，获得明确确认后再修改正文。
- 本地规范存在后，整理、补充或审查该课程笔记时优先读取并执行本地规范，不重复复制全局规范。
- 更新本地规范时保留课程特化；全局源规范升级后如需同步，比较差异，涉及冲突时先询问用户，不直接覆盖。
- 录音、视频和 ASR 转录仅在资料实际存在且与当前笔记任务相关时使用，不作为每节课笔记的固定输入。

### progress.md 表格体系

> progress.md 包含 5 张表格，分为持久表和临时表两类。

| # | 表名 | 性质 | 列 | 说明 |
|---|------|------|-----|------|
| ① | 里程碑表 | 持久，逐章追加 | 日期 / 里程碑 / 状态 | 全章级别的状态总览 |
| ② | 预估表 | 临时，每章新建 | 节 / PPT范围 / 预估用时 | 开始新章节时创建，纯计划用，学完清掉 |
| ③ | 学习明细表 | 临时，学习时填写 | 日期 / 时间段 / 内容 / 用时 / 备注 | 一行 = 一段连续学习，不绑定小节 |
| ④ | 答疑记录表 | 临时，学习时填写 | 日期 / 页码或概念 / 困惑点 / 结论 | 记录概念性的误解或混淆 |
| ⑤ | 用时参考表 | 持久，每章完成追加 | 章节 / 内容量 / 实际用时 / 学习方式 / 备注 | AI 校准预估的参考数据 |

**表③ 学习明细表**：
- 一行 = 一段连续学习时间，可以跨小节、可以只学半个小节
- 时间段为可选（有则写、无则留空），日期 + 用时为必填
- 备注列收录：讲解模式（逐页/逐小节/整大节）、用时偏差原因、跳过或调整说明
- 休息可选记录（加一行内容写"休息"即可）
- 习题学习也记在此表（内容列写"习题"）
- 同一小节分多天学习：日期写逗号分隔，用时写加法（如 35min (20+15)）

**表④ 答疑记录表**：
- 收录标准：用户对概念产生误解或混淆，经辨析后纠正的
- 不收录纯事实性提问

### 记录标准

> **progress.md 和 completed_tasks_log.md 的记录粒度必须达到：一个新开的对话窗口读完后，能直接接手继续教学，无需额外追问。**

具体要求：
- **不能只做要点提炼**：不是总结"学了什么知识"，而是记录"学到了哪一节"、"下一节是什么"、"有哪些遗留困惑"
- **状态要可操作**：当前进行中的章节要写清楚学到哪里、下一步具体从哪里继续
- **上下文要完整**：用户曾经卡住的点、待确认事项，凡新对话需要知道的都要记录

### 对话初始化

AI 每次新对话读完 memory.md 后，必须：
1. 读 `progress.md` — 了解当前在学什么、预估表是否已存在、待办事项
2. 若 progress.md 已有当前章节的预估表，简要告知用户当前进度即可，不重新估算

### 迁移 SOP（一章学完时执行）

1. **表③ 学习明细表 + 表④ 答疑记录表** → 剪切到 `completed_tasks_log.md`
2. **表⑤ 用时参考表** → 追加一行汇总
3. **表① 里程碑表** → 该章标 ✅
4. **清空** progress.md 当前章节区域（表②③④）
5. **笔记产出** → 在 completed_tasks_log.md 条目末尾列出文件清单

### 注意事项

- **笔记 ≠ 已学完**：笔记是 AI 生成的学习材料，不代表用户已学完。只有用户明确说"学完了"才标记 ✅
- **笔记补充原则**：用户学习中的困惑和解答，应同步补充到笔记中，体现"为什么容易搞混"和"正确理解是什么"，不删除原始内容，在旁边追加澄清
```
