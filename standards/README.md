安装时把需要的插件正文复制到目标课程 `.agent/plugins/`，再在该课程的 `memory.md` 登记版本、读取时机和课程配置。插件用于补充某类任务，不要求每个项目都安装全部插件；已登记也不意味着每轮对话全部读取。

课程的专用要求放在本地插件开头的“课程特化规则”中。升级时比较新旧正文，只更新通用部分并保留课程特化；规范库变化不自动覆盖正在使用的项目。

[ASR插件维护记录](上下文规范/课程学习/插件/ASR录播整理维护记录.md)保留版本演进，日常执行读取插件正文即可。

## 阅读原文中的环境约定

这些正文保留了个人系统的历史路径、宿主工具名称和示例，便于理解当时的实际组织方式。`D:\Antigravity-Hub` 表示共享工具与规范库，`D:\TJU-Notes` 表示课程和项目资料；在自己的环境中替换为对应位置。`view_file`、`ask_followup_question` 等名称代表当时助手的能力，其他宿主可使用等价的看图、读取及确认方式。

原稿中的学习方法私人笔记链接已改为文字来源说明；运行中的个人进度未随规范源发布。完整架构和公开命令的对应关系见 [架构与使用](../docs/architecture.md)及 [Hub 工具入口](../hub/README.md)。
