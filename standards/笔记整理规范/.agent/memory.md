## 维护规则

1. `memory.md` 只保存稳定导航、文件职责和维护规则；当前状态与待办写入 `progress.md`。
2. PPT 与视频使用各自的整理规范，不建立额外的通用笔记规范。
3. 素材获取和工具调用流程与最终成文规范分开维护。
4. 新增、改名、移动或删除文件后，同步更新本索引和上级 `规范\.agent\memory.md`。
5. 历史归档及已结束课程中的旧定制文件不随本规范包迁移。
