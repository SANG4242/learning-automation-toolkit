# Markdown 图片本地化工具

## 功能

批量将 Markdown 文件中的**在线图片**下载到本地，并自动替换链接。

采用 **Typora 风格**：每个 `.md` 文件对应一个 `文件名.assets/` 文件夹。

## 用法

```powershell
# 扫描统计（不下载）
python "d:\TJU-Notes\工具脚本\Markdown图片本地化\localize_md_images.py" "目标目录" --dry-run

# 正式下载并替换
python "d:\TJU-Notes\工具脚本\Markdown图片本地化\localize_md_images.py" "目标目录"
```

## 示例

```powershell
# 先看看有多少在线图片
python "d:\TJU-Notes\工具脚本\Markdown图片本地化\localize_md_images.py" "d:\我的笔记" --dry-run

# 确认后执行下载
python "d:\TJU-Notes\工具脚本\Markdown图片本地化\localize_md_images.py" "d:\我的笔记"
```

## 效果

### 处理前

```markdown
![示意图](https://example.com/images/abc123.png)
```

### 处理后

```markdown
![示意图](./文章标题.assets/abc123.png)
```

文件结构：
```
文章标题.md
文章标题.assets/
└── abc123.png
```

## 支持格式

- Markdown 图片语法：`![alt](url)` 和 `![alt](url "title")`
- HTML 图片标签：`<img src="url">`

## 注意事项

1. **建议先用 `--dry-run`** 查看统计，确认无误后再正式下载
2. 下载大量图片时可能需要几分钟，请耐心等待
3. 已经是本地路径的图片会自动跳过
4. 原 Markdown 文件会被直接修改，建议先备份
